### 아키텍쳐 구조 개선

- 기존엔 너무 많은 블로그와 공식문서의 구조들이 합쳐진 구조로 정확한 기준 없이 모호한 상태 🥲

- 예시의 아키텍쳐 구조를 보고, 지금 내 파일 구조를 보고 알맞게 수정 (예시의 아키텍쳐 기반)

---

1. 기존에는 SystemBroadcastReceiver가 ui/components/에 속해 있어 역할이 모호했지만,<br>
   ui/components/에는 Pure UI 뷰만 남기고, 로직은 util/effect로 옮겨 역할을 분리했다.
2. 이 과정에서 UI와 완전히 독립시켜, 불필요한 UI 패키기 참조 없이도 모든 레이어에서 사용할 수 있다.
3. 역할 기반 폴더 구조를 도입해 코드 탐색성을 높였고, 프로젝트 확장에 용이해졌다.
